Vega Virtual Device observations

Race-start freeze

a deadlock inside Vega's JS-thread watchdog
Seen
About 1 race start in 4 froze on "3", then the app was killed as AppNotResponding.
Cause
The JS thread blocks in send() to the watchdog while holding its mutex; the watchdog's loop, the only reader, waits for that mutex.
6 lanes
About 66 ink-blot images mounting at race start set it off again: 3 of 7 starts froze.
Fix
One JS task per frame, animated values native from birth, blots mount lane by lane.
52 race starts, 0 freezeson the fixed builds; then 30 more with race audio back on, 0 freezes

Media player crash

a SIGSEGV in libW3CMedia
Seen
The app dropped to the launcher as a creature's voice line ended and the next began.
Cause
Each clip got a new MediaSource. Swapping it detached the old source while its pipeline was still finishing, and a libW3CMedia thread then used it.
Proof
Five crash reports with the same 6-frame stack.
Fix
One AudioPlayer and one long-lived MediaSource for the whole session.
0 crashes in 73 screensof Reveal and Results; on the old code, 5 crashes in 216 clips
