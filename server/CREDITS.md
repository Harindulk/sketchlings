# Server credits and licences

Everything the server uses to make audio, with its licence. No cloud TTS, no third-party recordings, and no macOS
`say` voices in any shipped or served audio.

## Speech model and voices

| What | Version / source | Licence |
|---|---|---|
| Kokoro-82M TTS model (weights), by hexgrad | [hexgrad/Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) | Apache-2.0 |
| Kokoro-82M ONNX export (the file we run: `onnx/model.onnx`, fp32) | [onnx-community/Kokoro-82M-v1.0-ONNX](https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX), revision `1939ad2a8e416c0acfeecc08a694d14ef25f2231` | Apache-2.0 |
| Kokoro voice packs used: `af_heart af_bella af_sarah am_puck am_michael am_fenrir bf_emma bf_isabella bm_george bm_fable` | bundled in `kokoro-js` 1.2.1 (`node_modules/kokoro-js/voices/*.bin`), from hexgrad/Kokoro-82M | Apache-2.0 |

The Kokoro model card states it was trained only on permissive or non-copyrighted audio (for example Apache/MIT
licensed, public domain and synthetic audio). The narrator uses `af_heart`.

## Music (in the TV app)

`assets/music/menu.m4a` and `race.m4a` are re-encoded (AAC, mono, quieter) from two CC0 1.0 tracks, the same ones the
demo video uses. The TV app bundles them (`tv/scripts/bundle-music.mjs`). No attribution is
required; we credit the authors anyway.

| File | Title | Author | Source | Licence |
|---|---|---|---|---|
| `menu.m4a` (menus, Lobby, Reveal, Results) | Happy Clappy Loop | OwlishMedia | https://opengameart.org/content/happy-clappy-loop | CC0 1.0 |
| `race.m4a` (the race) | Happy Beat | burabotti | https://opengameart.org/content/happy-beat | CC0 1.0 |

## Generated audio

- `assets/narrator/*.m4a` (11 host lines) and the per-creature clips in `data/voice/` are generated by this project
